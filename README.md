## HelpHub

A full-stack counseling marketplace prototype with a cross-platform Expo/React Native frontend and a TypeScript/Express backend.

**Deliverables**

- Responsive Expo Router frontend optimized for web, iOS, and Android
- Reusable UI sections: hero slider, consultant cards, featured rails, appointment selection
- Responsive mobile and desktop navigation with mega-menu and account dropdown behavior
- NativeWind/Tailwind styling for consistent cross-platform UI
- Frontend flows for login, sign-up, consultant discovery, and appointment booking
- Express/TypeScript backend with Prisma ORM and PostgreSQL support
- Docker Compose setup for local database and backend development
- Test strategy documented with Jest and Playwright guidance

## Bakery & Restaurant Application

A Django-based full-stack food ordering solution with REST APIs, Stripe checkout, and cart persistence.

**Deliverables**

- Backend models, serializers, and REST endpoints for products, addons, cart actions, orders, and checkout
- Anonymous cart persistence and merge logic after user login
- Stripe checkout integration with success/cancel handling
- User profile, address management, order history, and admin order controls
- Responsive frontend pages using HTML, CSS, and vanilla JavaScript
- Custom error pages and WhiteNoise static file handling for production readiness
